Đọc requirement cùng Claude

Đừng đọc một mình. Nhờ Claude tóm tắt, liệt kê câu hỏi clarify, nhận diện dependency & risk trước khi code.

✕ Đọc một mình
  • Bỏ sót edge case ẩn trong mô tả
  • Không biết hỏi gì để clarify
  • Estimate thiếu buffer cho risk
  • Mất 2–3 giờ để hiểu hết
    • ✓ Đọc cùng Claude
  • Highlight ambiguity ngay lập tức
  • Có sẵn list câu hỏi cho PM
  • Risk được nhận diện trước khi code
  • Chỉ mất 20–30 phút
    • ⊕ Rule of thumb khi ET

    Luôn thêm 15% buffer vào ET của Claude — AI không nắm hết technical debt & server performance. Claude cho baseline, bạn điều chỉnh theo thực tế.

    Self-test = tôn trọng
    công sức của mình

    Nhờ Claude sinh checklist phủ đủ 4 nhóm — để không bỏ sót test case quan trọng trước khi chuyển tester.

    Happy path
    Luồng chính hoạt động đúng
    Edge cases
    Giá trị biên, dữ liệu bất thường
    Negative cases
    Input sai, xử lý lỗi đúng cách
    Regression
    Không break feature liên quan
    ⊕ Phép tính đơn giản

    Bug catch ở self-test = 5 phút. Bug do tester tìm ra = thêm 30 phút (re-open → assign → fix → re-test → close).

    không tái phát

    1
    Reproduce trước khi fixChưa tái hiện được thì chưa fix. Nhờ Claude tạo test case.

    3

    4
    Implement & review fixNhờ Claude review để đảm bảo không gây side effect.
    5
    Test regressionVerify fix không break feature khác.

    Anti-patterns hay mắc

    ✕ Tránh
  • Paste cả file 500+ dòng
  • Không confirm plan trước khi code
  • Để Claude làm sai đến cuối mới ESC
  • Agentic mode khi chưa hiểu rõ task
  • Kết nối MCP MySQL vào production
    • ✓ Đúng cách
  • Chỉ paste hàm/class liên quan
  • Plan → review → confirm → code
  • Sai bước 1 → ESC ngay
  • Chỉ Agentic khi requirement 100% rõ
  • Chỉ staging, read-only user
    • ⊕ Nhớ

    Self-test trước khi chuyển tester: 5 phút tự test = giảm 30 phút re-open. CLAUDE.md là living doc — update ngay khi convention đổi.

    Quick Reference

    Cheat Sheet

    Trước khi code

    CLAUDE.md sẵn sàng → lên plan → review → confirm → mới implement.

    Khi debug

    5 thành phần: error · reproduce · expected/actual · recent change · env.

    Khi ET

    Hiểu requirement → breakdown effort → +15% buffer.

    Tiết kiệm token

    Chỉ code liên quan · gộp câu hỏi · ảnh 720p · ESC khi sai.

    Trước khi push

    /review + self-test checklist: happy · edge · negative · regression.

    Team scale

    Slash commands + Skills commit lên Git, cả team dùng chung.
